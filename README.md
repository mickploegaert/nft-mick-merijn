## 🎨 Over dit project

Dit is een NFT (Non-Fungible Token) project gebouwd met React. Het project bevat een moderne UI voor het weergeven en beheren van NFT collecties.

## 🚀 Installatie

### Vereisten
- Node.js (versie 14 of hoger)
- npm of yarn

### Stappen

1. Clone de repository:
```bash
git clone https://github.com/mickploegaert/nft-mick-merijn.git
cd nft-mick-merijn
```

2. Installeer dependencies:
```bash
npm install
```

3. Start de development server:
```bash
npm start
```

De applicatie opent automatisch in je browser op `http://localhost:3000`

## 💻 Development

### Beschikbare Scripts

- `npm start` - Start de development server
- `npm build` - Bouwt de app voor productie in de `build` folder
- `npm test` - Voert de tests uit
- `npm run eject` - Eject uit Create React App (onomkeerbaar!)
